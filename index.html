Baca sebelum memesan supaya proses lancar dan garansi tetap berlaku.

❗ LITERACY BEFORE ORDERING ❗ 𓋰 PERMANENT (TERGANTUNG SERVER) 𓋰 REFILL / NO REFILL (TERGANTUNG SERVER) 𓋰 TF ➢ BUKTI TF ➢ LINK SOSMED ➢ PROSES 𓋰 MAXIMAL 24 JAM 𓋰 ORDER = PAHAM

Ketika Order

  1. Akun wajib publik. Pastikan akun/postingan target tidak privat selama proses berjalan.
  2. Jangan ganti username / hapus link saat pesanan sedang dikerjakan.
  3. Periksa link & username. Salah tulis oleh pembeli bukan tanggung jawab admin.
  4. Hindari order ganda — jangan pesan layanan sama di dua tempat untuk satu link/akun bersamaan.
  5. Tanpa password. Pesanan diproses setelah bukti transfer diterima.

Ketika Komplain

  1. Sertakan bukti lengkap: bukti transfer, username/link target, serta jumlah sebelum & sesudah proses.
  2. Tunggu estimasi maksimal 24 jam sebelum mengajukan komplain pesanan belum masuk.
  3. Refill / drop: refill hanya untuk server yang mendukung refill/permanen; paket no refill tanpa garansi isi ulang.
  4. Garansi hangus jika akun diprivat, username diganti, postingan dihapus, atau order ganda.
  5. Komunikasi sopan agar pengecekan ke server bisa diproses dengan lancar.
